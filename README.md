## The entry

`main.ts` (Node 22, stdlib only) writes a single word to `/output/entry.txt`:

**Ghosting**

Home Wi-Fi that vanishes mid-call, mid-download, mid-sentence — with no
goodbye and no explanation — then reappears later as if nothing happened.
It ghosts you, exactly like a bad date. Funnier and truer than "slow" or
"buffering", and understood the instant you read it.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The program validates the gate itself (one word, 1–20 characters, not only
whitespace) and verifies the written bytes round-trip before exiting.
